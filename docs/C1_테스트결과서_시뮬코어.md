## 5. 자체 점검
- **결정성**:
  - 서버 x86_64 의 GDScript · Python 기준 구현 · 공개 데모 수열, 셋이 같다. CI 러너 · CI 에뮬레이터(x86_64 Android 14)도 같다.
  - arm64(폰)는 자가 해시로 본다(8절). CI 에뮬레이터는 x86_64 라 같은 아키텍처 확인일 뿐이다.
- **지우는 일**: verify 커버리지 단계는 `.tools/cov/` 만 지우고 다시 만든다. 시험은 자기가 만든 `user://test_save_resume.json` 만 지운다.
- **옮겨 적은 것**: castle_M3D 에서 옮긴 러너 본문은 원본과 diff 가 같다(머리 주석만 다름). verify · get_godot · emu_check 는 맞춰 고쳤다(설계서 · 요구사항정의서 8절).
- **고친 결함**: 실행 인자 파서가 틀린 값을 다음 인자로 읽던 것(초록 단계 1회) · 화면이 최소 크기로 쪼그라들던 것(7절).
