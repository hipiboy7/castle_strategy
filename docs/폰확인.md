## 📱 설치

1. 휴대폰 **GitHub 앱** → **Repositories** → `castle_strategy` → **Releases** → 맨 위 릴리스
2. **Assets** 에서 `castle_strategy-<버전>.apk` 를 눌러 받고 → 열어서 **설치**(처음이면 '출처를 알 수 없는 앱' 허용)
3. 다음 판부터는 같은 서명 키라 그대로 덮어 설치된다(저장 유지)
