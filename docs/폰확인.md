## 📱 설치

1. 휴대폰 **GitHub 앱** → **Repositories** → `castle_strategy` → **Releases** → 맨 위(**Latest**) 릴리스
2. 본문 맨 위 **바로 받기** 링크(또는 아래 **Assets** 의 `castle_strategy-<버전>.apk`)를 눌러 받고 → 열어서 **설치**(처음이면 '출처를 알 수 없는 앱' 허용)
3. 다음 판부터는 같은 서명 키라 그대로 덮어 설치된다(저장 유지)

## ⏱ 1분 플레이 경로 (C3 — 습격 · 일기토 · 전투 화면 · 시나리오 A 끝까지)

앱을 켜면 회암시 지도가 뜬다(나 = 부진파 `[부]` · 적 = DS 씨큐리티 `[D]` · 회색 `·` = 주인 없음). 앞 판 저장이 있으면 그 주에서 이어진다 — 앞 판이 26주로 끝나 있으면 아래 단추가 **새 판으로** 로 바뀐다(눌러서 1주부터). 처음부터 하려면 **기록** 탭 → **새 판으로**도 된다. 받지 않은 손 입력은 아래 작은 글에 까닭이 뜬다.

1. 아래 간부 줄의 **김신 ★** 을 끌어 **회암 시장**(`D`)에 놓는다 → 고르기 창에서 **습격 · 기습 — 결과는 주 끝 보고** (끌기가 안 되면 김신을 누른 뒤 회암시장을 누른다)
2. **서진태** · **피우진** 도 회암 시장에 놓아 **습격 · 카드 없음** (같은 구역 습격은 한 싸움으로 묶인다 — 간부 4명까지)
3. **주 끝내기** → 보고 맨 앞 **목표**(차지한 구역 n / 4) 밑 **전투** 카드에서 결과 · 구간 · 일기토 줄을 보고 → 카드의 **전투 보기 1** 또는 아래 **닫기** 옆 **전투 보기**
4. 전투 화면: 위 = DS · 아래 = 우리 · **일기토 장면**(구간 안에서 두 쪽 간부가 마주치면 저절로 나온다 — 두 사람 초상 · 체력 · 낸 카드 · 1주 회암 시장은 김신이 셋과 붙는다) → **×1** 을 눌러 ×2 · ×4 → **건너뛰기**(다음 구간) → **결과만** → **닫기** → 보고 **닫기 — 2주로**
5. 이제 **맡기기 → 주 끝내기 → 닫기** 를 되풀이한다 — 4주 안팎에 보고 맨 앞에 **승리 — 부진파**(판의 구역을 모두 차지) 카드가 뜬다. 그 뒤에도 26주까지 이어서 둘 수 있다
