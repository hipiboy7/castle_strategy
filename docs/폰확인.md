## 📱 설치

1. 휴대폰 **GitHub 앱** → **Repositories** → `castle_strategy` → **Releases** → 맨 위(**Latest**) 릴리스
2. 본문 맨 위 **바로 받기** 링크(또는 아래 **Assets** 의 `castle_strategy-<버전>.apk`)를 눌러 받고 → 열어서 **설치**(처음이면 '출처를 알 수 없는 앱' 허용)
3. 다음 판부터는 같은 서명 키라 그대로 덮어 설치된다(저장 유지)

## ⏱ 1분 플레이 경로 (C1 시뮬 코어 — 시나리오 A)

앱을 켜면 '캐슬 제패' 화면이 뜬다. 시나리오 A(귀국 — 회암시)를 부진파로 시작한다 — 아직 명령 화면이 없어 모든 조직을 컴퓨터가 경영한다(명령 화면은 C2).
**다음 주** 를 여러 번 눌러 '1주 / 26 → 2주 / 26 → …' 로 오르고 '부진파 돈 · 사업장' 이 바뀌는지 본다. 홈으로 나갔다가 다시 열어 같은 주에서 이어지는지 본다. 26주를 넘기면 '끝 — 26주' 가 되고 버튼이 꺼진다.
