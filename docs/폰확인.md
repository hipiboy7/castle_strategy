## 📱 설치

1. 휴대폰 **GitHub 앱** → **Repositories** → `castle_strategy` → **Releases** → 맨 위(**Latest**) 릴리스
2. 본문 맨 위 **바로 받기** 링크(또는 아래 **Assets** 의 `castle_strategy-<버전>.apk`)를 눌러 받고 → 열어서 **설치**(처음이면 '출처를 알 수 없는 앱' 허용)
3. 다음 판부터는 같은 서명 키라 그대로 덮어 설치된다(저장 유지)

## ⏱ 1분 플레이 경로 (C4-2 — 주 끝내기에서 습격을 직접 싸운다)

앱을 켜면 지금까지와 같은 세로 지도가 뜬다(옛 저장은 v2 로 옮겨 이어 한다). 이번 판은 **내 습격이 실시간 전투로 이어지는 것**을 본다.

1. 깨끗하게 보려면 아래 탭 **기록** → **새 판으로** → 확인(1주부터)
2. 아래 **맡기기** → **주 끝내기** — 부진파가 회암시장을 습격한다
3. **전투 방식** 창: **직접** · **자동 플레이 보기** · **결과만 보기** · 나중에 — **직접**을 누른다
4. 화면이 **가로**로 바뀌고 조종할 간부를 고른다 → 입구 · 안 · 본진을 차례로 싸운다(이기면 같은 화면에서 다음 구간). 오른쪽 위 **자동**(봇에게 넘기기 ↔ 다시 직접) · **×1/×2/×4** · **멈춤** · 뒤로 버튼 두 번 = **건너뛰기**(이 구간은 봇이 빨리 · 남은 구간은 결과만)
5. 끝나면 **세로**로 돌아와 그 주 **보고** — 전투 카드에 `입구 뚫음(직접)` 과 구간마다 '직접 — N초 · 쓰러뜨림 우리 N · 적 N'
6. **기록** 탭 **전투 방식: 매번 묻기** 단추 — 누를 때마다 늘 직접 → 늘 자동 플레이 보기 → 늘 결과만 → 매번 묻기

## ✅ 이번에 볼 것 (C4-2)

- [ ] **창**: 주 끝내기 뒤 전투 방식 창이 뜨는지 · 세 단추가 손가락으로 잘 눌리는지 · '나중에'면 지도로 돌아오고 다시 주 끝내기로 이어지는지
- [ ] **직접 → 보고**: 3구간 뒤 세로 · 보고 카드의 '직접' 표시 · 구역 주인이 바뀌는지(이겼으면)
- [ ] **자동 플레이 보기 · 결과만**: 자동은 봇이 싸우는 것을 보여 주는지 · 결과만은 전투 화면 없이 바로 보고
- [ ] **건너뛰기**: 뒤로 두 번 → 바로 끝나고 남은 구간은 화면 없이 보고(구간 줄에 '자동' 하나 + 틱)
- [ ] **이어 하기**: 전투 중 홈으로 나갔다 앱을 지우지 않고 돌아오면 멈춘 채 '계속' · 앱을 완전히 닫았다 다시 열면 끝낸 구간은 그대로, 하던 구간부터 다시(주 끝내기를 다시 누름)
- [ ] **설정**: 기록 탭 '전투 방식'을 '늘 결과만'으로 바꾸면 다음 주부터 창이 안 뜨는지 · 앱을 다시 켜도 그대로인지
- [ ] **성능**: 기록 탭 '성능' 줄 전투 fps 평균 · 최저(예산 최저 30)
- [ ] **C4-1 그대로**: 기록 탭 '전투 시험' · 간부 고르기 · 교대 · 효과음 · 접기/펴기
