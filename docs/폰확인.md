## 📱 설치

1. 휴대폰 **GitHub 앱** → **Repositories** → `castle_strategy` → **Releases** → 맨 위(**Latest**) 릴리스
2. 본문 맨 위 **바로 받기** 링크(또는 아래 **Assets** 의 `castle_strategy-<버전>.apk`)를 눌러 받고 → 열어서 **설치**(처음이면 '출처를 알 수 없는 앱' 허용)
3. 다음 판부터는 같은 서명 키라 그대로 덮어 설치된다(저장 유지)

## ⏱ 1분 플레이 경로 (C4-0 — 전투 시험: 직접 움직여 싸우는 전투 화면 기술 검증)

앱을 켜면 지금까지와 같은 세로 지도가 뜬다. 이번 판은 **직접 움직여 싸우는 전투 화면**이 폰에서 도는지만 본다 — 아직 판(습격)과 이어지지 않았고, 한 판 해도 판에는 아무 일도 없다.

1. 아래 탭 **기록** → 목록 아래 **전투 시험(가로 화면 · 한 판)** 을 누른다
2. 화면이 **가로**로 바뀐다(폰을 가로로 쥔다). 김신 하나 대 건달 16명이다
3. 왼쪽 아무 데나 누르고 끌면 **이동**. 오른쪽 **치기**(이어 누르면 연타) · **쳐내기**(누르고 있으면 막기 · 흰 ! 에 맞춰 누르면 쳐내기) · **구르기**(빨간 ! 를 피한다) · **대시** · **기술**(왼쪽 위 파란 칸이 차면 — **바꾸기**로 고른다)
4. 오른쪽 위 **자동**(봇이 대신 싸운다 ↔ **직접**) · **×1**(누르면 ×2 · ×4) · **멈춤**
5. 다 쓰러뜨리면 '이겼다' → 조금 뒤(또는 누르면) **세로 화면**으로 돌아오고, 아래 작은 글에 결과와 전투 fps 가 뜬다 → **기록** 탭 '성능' 줄의 **전투 fps**

## ✅ 이번에 볼 것 (C4-0)

- [ ] **가로 전환**: 접은 화면(커버)과 편 화면(안쪽)에서 각각 — 가로로 잘 돌아가는지 · 화면이 잘리거나 찌그러지지 않는지 · 끝나면 세로로 돌아오는지
- [ ] **접기 · 펴기**: 전투 중에 접었다 펴도 이어지는지 · 단추 자리가 다시 잡히는지
- [ ] **조작**: 이동 스틱 · 치기 · 쳐내기 · 구르기 · 대시 · 기술 · 바꾸기가 눌리는지 · 누르는 넓이가 손가락에 맞는지 · 손맛
- [ ] **그림**: 김신 · 건달 인형과 방이 제대로 보이는지(검게 나오거나 깨지는 곳) · 글자가 읽히는지
- [ ] **자동 · 속도 · 멈춤 · 뒤로 버튼**(한 번 = 멈춤 · 한 번 더 = 그만두기 — 봇이 남은 싸움을 끝낸다)
- [ ] **백그라운드**: 전투 중 홈으로 나갔다 오면 멈춘 채 돌아오는지
- [ ] **성능**: 기록 탭 '성능' 줄 — **전투 fps** 평균 · 최저(예산: 최저 30 이상 · 목표 60) · **지도 fps** 평균 · 최저(지도 탭을 10초 가만히 둔 뒤 — 예산 55 이상 · C3 에서 미룬 것) · 켜기 · 마지막 주 처리
- [ ] **앞 판(C3) 그대로**: 맡기기 → 주 끝내기 → 보고 → 전투 보기가 전과 같이 되는지 한 번

결과는 Claude 세션에 한두 줄로 알려 주면 된다(예: "가로 OK, 조작 OK, 전투 fps 평균 58 · 최저 41, 지도 fps 60 · 55, 접기 펴기 OK" — 안 본 것은 '안 봄'). 전투 화면 스크린샷 한 장을 주면 `docs/screenshots/C4/` 에 남긴다.
