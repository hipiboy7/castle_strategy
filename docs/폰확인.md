## 📱 설치

1. 휴대폰 **GitHub 앱** → **Repositories** → `castle_strategy` → **Releases** → 맨 위(**Latest**) 릴리스
2. 본문 맨 위 **바로 받기** 링크(또는 아래 **Assets** 의 `castle_strategy-<버전>.apk`)를 눌러 받고 → 열어서 **설치**(처음이면 '출처를 알 수 없는 앱' 허용)
3. 다음 판부터는 같은 서명 키라 그대로 덮어 설치된다(저장 유지)

## ⏱ 1분 플레이 경로 (C2 — 지도 · 명령 · 턴 끝 보고 · 시나리오 A)

앱을 켜면 회암시 지도가 뜬다(나 = 부진파 `[부]` · 적 = DS 씨큐리티 `[D]` · 회색 `·` = 주인 없음 · 붉은 선 = 전선). 앞 판(C1) 저장이 있으면 그 주에서 이어진다 — 26주가 끝났거나 처음부터 하려면 **기록** 탭 → **새 판으로**.

1. 지도에서 **회암시 부진**을 눌러 구역 카드(사업장 · 주둔 · 내 주 수입)를 본다 → **닫기**
2. 아래 간부 줄의 **김신 ★** 카드를 끌어 **회암시 남구**(회색)에 놓는다 → 고르기 창에서 **이동** (끌기가 잘 안 되면 김신 카드를 누른 뒤 남구를 누른다)
3. 김신을 다시 **남구**에 놓는다 → **개업 — N만 원** (두목은 행동 둘 — 이동한 자리에서 개업)
4. 나머지 간부는 **맡기기** 로 채우거나 그대로 두고 → **주 끝내기** → 보고(돈 · 내 명령 · 다른 조직 · 전투) → **닫기 — N주로**
5. 4 를 되풀이해 **5주**를 둔다(맡기기 → 주 끝내기 → 닫기만 해도 된다)

## ✅ 이번에 볼 것 (C2)

- [ ] **설치 · 이어 하기**: 앞 판(v0.1.0-rc.2) 위에 덮어 설치되고, 앞 판 저장의 주에서 이어지는지(아래 작은 글자 '이어 하기 — N주') · 기록 탭 **새 판으로**가 1주로 되돌리는지
- [ ] **지도 · 구역 카드**: 노드 글자(`부` · `D` · `·`) · 이름 · 경찰 칸(파란 막대)이 보이는지 · 구역을 누르면 카드가 아래에서 뜨고 지도가 그 위로 줄어드는지
- [ ] **끌어 놓기**: 간부 카드를 끌어 구역에 놓으면 고르기 창이 뜨는지(노란 테두리가 놓을 자리) · 누르기 두 번(간부 → 구역)도 되는지 · 안 되는 줄에 까닭이 보이는지
- [ ] **남은 행동**: 명령을 넣을 때마다 위 '행동 n / 6' 과 간부 카드의 ●○ 가 줄어드는지 · **명령** 탭에서 대기 명령을 **빼기** 할 수 있는지
- [ ] **턴 끝 보고**: 주 끝내기 뒤 보고 카드 넷이 뜨는지 · 내 명령 ○ / × 와 돈 증감이 맞아 보이는지 · **기록** 탭에 지난 보고가 쌓이고 눌러 다시 보이는지
- [ ] **5주**: 5주를 두어 위 '6주 / 26' 이 되는지
- [ ] **접기 · 펴기**(폴드 4): 펴면 지도 + 옆 패널(구역 카드 · 탭 내용), 접으면 쌓기로 바뀌는지 · 고른 구역 · 대기 명령이 그대로인지
- [ ] **뒤로 버튼**: 고르기 창 · 보고 · 카드 → 고른 간부 → 다른 탭 순으로 닫히고, 마지막에 '끝낼까요?'
- [ ] **저장**: 명령을 넣은 채 홈으로 나갔다가 다시 열면 대기 명령이 남아 있는지
- [ ] **성능**: 기록 탭 '성능: 켜기 N ms · 마지막 주 처리 N ms · N fps' 의 세 숫자(예산 — 3초 · 100 ms · 55 fps 이상)
