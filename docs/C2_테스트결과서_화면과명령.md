## 5. 자체 점검 (완료 기준 대비)
- **새 표 · 칸**: 저장 v1 에 선택 칸 `pending` — 쓰기(`Save.make`) · 읽기(없음 = [] · 틀린 것 버림) · id 옮기기(`_rename`) 모두 안다(test_save). 형식 버전은 그대로다 — C1 앱은 모르는 칸을 무시한다. 정적 표에 `t["names"]`(저장 밖). `Orders.KINDS` 에 `at`(화면 쓰임 · 시뮬은 안 씀).
- **지운 것**: C1 화면 ui/home.gd(`ui/app.gd` 로 바뀜). C1 문서의 코드 표기는 정정 이력과 함께 고쳤다. CI 의 APK 안 파일 점검 목록도 고쳤다(배치 ③-1 run 실패 → 고침 — 7절).
- **결정성**: 미리 보기는 `Turn.phases`(턴과 같은 ctx · 갈래 난수)라 실제와 같다(test_player_turn 5주). 화면은 상태를 직접 고치지 않는다(대기 명령 · 판은 app 이 sim 함수로만 바꾼다).
- **위험 · 남은 것**: 끌어 놓기는 서버에서 누를 수 없어 폰에서만 본다(누르기 두 번이 같은 결과). AI 가 '쉼'을 많이 고른다(밸런스 C7). 지도 32구역 좌표 · 길은 잠정이다(B 에서 다시 본다). 첩보 가림 없음(C4).
