## 1. 데이터 흐름 (C1 1절에 화면 쪽을 더함)
```
            sim/game.gd ── g = {state, log, errors, reports}
  ui/app.gd ─┤   step_player(g, t, draft) = 내 조직 draft + 다른 조직 Ai.orders_for → Turn.run
 (상태 기계)  │
     │       └─ sim/draft.gd  대기 명령(순수): add · remove · left · preview(사본에 plan → move → manage) · options · auto
     │
     ├─ ui/view.gd       읽기 전용 보기(순수 · 상태 + 표 → 사전): 위 막대 · 지도 노드 · 구역 카드 · 간부 카드 · 보고 카드 · 조직 · 글 꼴
     ├─ ui/layout.gd     틀 사각형(순수): 좁음 = 쌓기 · 넓음 = 지도 + 옆 패널 · 안전 영역
     ├─ ui/map_layout.gd 지도 맞춤 · 노드 반지름 · 누르기 판정(순수)
     └─ 장면 부품(노드 · 그리기만): map_view · zone_card · officer_strip · order_picker · report_view · *_tab · sprites
```
- 장면은 보기 사전을 그리고, 누름 · 끌어 놓기를 app 에 신호로 올린다. app 만 `draft` 와 `g` 를 바꾼다(ISP — 부품은 상태를 직접 고치지 않는다).
- `ui/view.gd` · `ui/layout.gd` · `ui/map_layout.gd` 는 노드 · 텍스처 · 테마를 읽지 않는다. 치수는 app 이 테마 상수에서 읽어 인자로 넘긴다(커버리지 사본에는 자산이 없다).

## 3. 화면 구조
- **틀**(`Layout.frame` → 사각형 사전 · 기준 화면 단위):
  - 좁음(가로 ÷ 세로 ≤ 0.8 — 커버 · 기준 9:16): 위 막대 / 몸통(탭 내용 — 지도 탭이면 지도) / 간부 줄(지도 탭만) / 행동 줄 / 아래 탭.
  - 넓음(> 0.8 — 폴드 안쪽): 위 막대 / 몸통 = 왼쪽 지도(늘) + 오른쪽 옆 패널(지도 탭이면 구역 카드 · 다른 탭이면 그 탭 내용) / 간부 줄 / 행동 줄 / 아래 탭.
  - 치수는 테마 `Frame` 상수(`top_h` · `strip_h` · `actions_h` · `tabs_h` · `gap` · `side_min` · `side_ratio`).
- **화면 상태**(app 이 든다 — 배치가 바뀌어도 남는다): `tab` · `zone`(고른 구역) · `officer`(고른 간부 — 누르기 두 번) · `sheet`(`""` · `card` · `pick` · `report`) · `report_i`.
- **상태 기계**: `loading`(표 · 저장 읽기 · 보고 다시 만들기) → `play` ↔ `report`(주 끝내기 뒤 · 닫으면 play) → `over`(26주 뒤 — 승패는 C5) / `error`(데이터 · 저장 — 까닭 + 새로 시작).
- **뒤로**: 고르기 창 → 카드 → 보고 → 고른 간부 순으로 닫고, 다 닫혔으면 '끝낼까요?'.
- **수명주기**: 주 끝내기 · 대기 명령이 바뀔 때 · 백그라운드에서 자동 저장. `--shot` 이면 저장을 읽지도 쓰지도 않는다.

## 4. 보기 · 명령 제출
- **보기**(`ui/view.gd` — 모두 `(s, t, …) -> 사전 · 배열` · 입력 불변):
  - `top(s, t, me, draft)` → 주 · 길이 · 돈 글 · 남은 행동 / 전체 · 주 순이익 예상 · 잠정 수.
  - `map_nodes(s, t, me, coords)` → 구역마다 `{id, name, owner, mark, police_lv(0~2), mine[간부 id], others(수), x, y}` (구역 id 순).
  - `fronts(s, t)` → 주인이 서로 다른(둘 다 있음) 이웃 쌍.
  - `zone_card(s, t, zid, me)` · `officer_cards(s, t, me, draft)` · `org_panel(s, t, me)` · `report_cards(rep, before, after, t, me)`.
  - 글: `money(n)`(만 원 · 억) · `mark(t, org)`(조직 이름 첫 글자 · 없으면 "·") · `order_text(t, s, o)`.
- **대기 명령**(`sim/draft.gd` — draft = 명령 배열 · `src: "player"`(맡기기는 `"ai"`)):
  - `limit(s, t, by)` · `left(s, t, d, by)` · `add(s, t, d, o) -> {draft, why}` · `remove(d, i)` · `clear()`.
  - `preview(s, t, d)` → 사본 상태에 `Orders.plan` → `run_phase(move)` → `run_phase(manage)` 를 돌린 `{state, applied, rejected}` — 턴과 같은 ctx(seed · turn · 갈래 난수)라 내 조직만 놓고 보면 실제 결과와 같다(다른 조직 명령이 먼저 빈칸을 가져가면 다를 수 있다 — 보고에 남는다).
  - `options(s, t, d, by, zone)` → 그 간부가 미리 본 상태에서 서 있는 구역이 `zone` 이면 `open · expand · recruit · rest`, 아니면 `move` 하나. 종류마다 `preview(d + [명령])` 로 받았는지 · 거절 까닭 · 쓴 돈 · 모집 수를 얻는다(처리기 검사를 다시 쓰지 않는다 — 등록부를 따라간다).
  - `auto(s, t, me)` = `Ai.orders_for(s, t, me)`.
- **주 끝내기**(`Game.step_player(g, t, draft)`): 명령 = draft + 조직 id 순으로 내 조직을 뺀 `Ai.orders_for` → `Game.step` 과 같은 길(불변식 · 기록). `g["reports"]` 에 보고를 쌓는다. 보고 카드를 위해 전 상태를 같이 둔다(`{report, before_turn}` — 전 상태는 다시 돌려 얻지 않고 그때 잡아 둔다).

## 5. 도트 받기 (`scripts/import_chars.py`)
- 고르는 인물: 장르 팩 시나리오 명단(roster) · assign 의 canon id ∩ 취호전 `looks_canon.CANON_ID`(키가 canon id 와 같으면 그 키, 아니면 정렬 첫 키 — 변형 `kimshin_coat` 등은 쓰지 않는다).
- 내보내기: 취호전 `tools/export_characters.py OUT 키… --ref <빈 폴더> --no-cards` → `.work/chars_export/`. 원작 조각은 읽지 않는다.
- 묶기: 대표 차림(base) `portrait_base.png`(32×32) · `field.png` 의 아래 방향 프레임 1(24×32)을 16칸 한 줄로 → `assets/chars/portraits.png` · `figures.png`. 칸 번호 = canon id 정렬 순.
- 색인 `assets/chars/index.json`: `source`(취호전 커밋 · 고친 파일 여부 · 도구 · 차림) · `cols` · `cell` · `ids`(canon id → 칸) · `keys` · `missing`(외형 없는 명단 인물).
- 화면: `ui/sprites.gd` 가 색인을 읽어 `AtlasTexture` 를 준다(없으면 null → 세력색 바탕 + 이름 첫 글자). 그림은 최근접 필터(`project.godot` 기본 텍스처 필터 Nearest).
- 시나리오 시점 차림(`looks_by_period` · 취호전 `BY_CHAPTER`)은 C6(원작 사건)에서 다시 본다.

## 6. 저장 — v1 + 선택 칸 `pending`
- `Save.make(meta, state, log, pending = [])` 가 `pending`(대기 명령 배열)을 쓴다. 불러오기는 없으면 `[]`, 있으면 명령마다 `Orders.shape_error` 로 보고 틀린 것은 버린다(알림 `대기 명령 n개 버림`). 이 판보다 옛 앱(C1)은 모르는 칸을 무시한다 — 형식 버전을 올리지 않는다.
- 이어 하기: 저장 상태로 연 뒤 `Game.rebuild_reports(t, sv)` 가 처음 상태에서 명령 기록을 다시 돌려 보고 목록을 만들고, 다시 돌린 상태 해시가 저장 상태 해시와 다르면 알림(`다시 돌린 해시가 다르다`)을 남긴다. 상태는 저장 상태를 쓴다.

## 7. 실행 인자 · 스크린샷 · 에뮬레이터
- `--view NAME`(`map` 기본 · `card` · `pick` · `orders` · `report` · `org` · `log` · `diplo`) · `--week N`(1 이상 · 기본 1 — 맡기기로 N−1주를 둔 뒤) · `--zone ID`(card · pick 에서 고를 구역 · 기본 = 내 본거지). `--shot` 이 없으면 `--view` 는 처음 탭만 고른다.
- 앱은 배치가 끝날 때마다 `UI <이름> <x> <y>`(창 화소 가운데 — 맡기기 `auto` · 주 끝내기 `end` · 보고 닫기 `close` · 탭 `tab_<id>`)를 찍는다. `scripts/emu_check.sh` 가 logcat 의 마지막 값을 눌러 1분 경로 일부를 돈다.
- `PERF boot_ms=<켜기 → APP ready> turn_ms=<마지막 주 처리> fps=<10초 평균>` 줄을 APP ready · 주 끝내기 · 10초마다 찍는다.

## 8. 테마 토큰 (`ui/theme.tres` — 장면에 직접 쓰지 않음)
- `Faction` 색: 조직 id 마다(00 7절 제안: 하성 회청 · 이스크라 짙은 녹갈 · 백의 흰색 … · 부진파 녹슨 주황 · DS 붉은 자주) + `none`(주인 없음).
- `Map` 색: `bg` · `link` · `front` · `select` · `drop` · `text` · `police` / 상수: `node_r_min` · `node_r_max` · `pad` · `line_w` · `front_w`.
- `Frame` 상수(3절) · 글 크기 변형(`TitleLabel` · `BigLabel` · `SmallLabel` · `CardTitle`) · 판 · 단추 모양.
