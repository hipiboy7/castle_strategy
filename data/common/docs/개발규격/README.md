## 2. 왜 `docs/기획서/` 가 아니라 이 폴더인가

- 기획서 = **무엇을** 만드나(판마다 · 설계 의도 · 원작 내용). 규격 = **어떻게** 만드나(모든 판 공통 · 과정 · 품질 · 약속). 고치는 때와 읽는 쪽이 다르다.
- `게임개발규격.md` 는 다른 저장소(agentic-sdlc)로 옮길 원고다. 원작 내용이 든 기획서와 한 폴더에 두면 옮길 때 가려내기 어렵다(CLAUDE.md 머리 — 원작 내용은 이 비공개 저장소 밖으로 올리지 않는다).
- 하류는 폴더째(`docs/개발규격/*.md`) 받는다. 기획서 폴더를 보내면 다른 판 기획서까지 간다.
- `rules/` 는 2층 게임 규칙(공식)이라 섞지 않는다. 맨 위에 새 폴더를 두면 층(0 · 1 · 2층 폴더)과 헷갈려서 `docs/` 아래에 뒀다.
